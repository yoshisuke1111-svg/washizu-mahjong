# 麻雀 v0.19

制作：鈾

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

鷲巣麻雀をモチーフにしたブラウザ試作版。オンライン部屋では最大4人の2対2対局ができます。空席はCPU。

## v0.19 スマホ専用の見やすい表示
- 卓上の対面・左右の牌を拡大
- 卓のすぐ下に大きな手牌列を設置。横にスワイプして全牌を確認
- 大きな手牌も2枚を順番にタップして理牌、選択後「打牌」で確定
- 相手の手牌も大きな横スクロール表示。相手の不透明牌の中身は表示しない
- 狭い画面でもページが横にはみ出さないよう調整

従来の透明牌枚数設定、血液レート・回復設定、部屋コード・招待URL、手動理牌、CPU対局を維持。

※通信は外部PeerJSサービスを利用した試験実装。別々の回線の実機同士では未検証です。部屋主がブラウザを閉じると部屋は終了します。血液はゲーム内数値のみです。
