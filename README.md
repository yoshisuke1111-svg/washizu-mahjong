# 麻雀 v0.17

制作：鈾

鷲巣麻雀をモチーフにしたブラウザ対局試作版。CPU3人との四人対局。

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## v0.17
- 筒子・索子・萬子・字牌の牌面を専用ベクター描画（SVG）へ刷新。切り抜き画像は不使用
- 透明牌の本体は青緑のガラス調、模様は不透明で読みやすい
- 不透明牌は明るい牌面と濃色の裏面に変更
- 手動理牌と、2枚を順にタップして位置を交換する操作に対応
- スマホ画面で手牌が切れにくいよう調整
- 中央の牌袋からの自動ツモ、点棒・血液表示、透明牌枚数設定

※ゲーム内の演出です。現実の出血・金銭取引はありません。オンライン対局や原作の細かな特殊ルールは開発途中です。
