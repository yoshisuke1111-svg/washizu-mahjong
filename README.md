# 麻雀 v0.21

制作：鈾

**[ブラウザで麻雀を開く](https://yoshisuke1111-svg.github.io/washizu-mahjong/)**

CPU対局、または友達とのオンライン部屋を利用できるブラウザ試作版。最大4人の2対2対局に対応し、空席はCPUが担当します。

## v0.21 の変更
- ツモ中の牌面を固定サイズに変更。スマホでは卓下の大きな手牌をそのまま着地点とする
- 捨て牌を各プレイヤーの前の**6枚×3段**の固定位置に並べ、牌が増えても並び全体が中央から広がらないよう修正
- 名前・川・手牌・中央の牌袋が重なりにくい配置へ変更。320～1440px幅で確認
- 血液量と減少アニメーションを**卓の上側**に移動
- スマホの独立した手牌操作エリアを、卓と同じ緑のフェルト色に変更
- 開始画面の余計な文章を削除
- CPUは2～4枚程度の小グループを前より多めに理牌しつつ、一種類の牌を片側に固めすぎない

## 操作
- スマホでは卓下の手牌をスワイプして閲覧し、2枚を順にタップして入れ替え
- 打牌するときは捨てる牌を選んで「打牌」
- 友達と遊ぶには「部屋を作る」→招待URLを共有→部屋主が開始

## 制約
オンライン通信は公開PeerJSサービスを使用した試験実装です。異なる実回線同士での実機接続は未検証で、部屋主のブラウザを閉じると部屋は終了します。原作の特殊ルールも開発途中です。血液の数値はゲーム内演出で、現実の出血・金銭取引はありません。
