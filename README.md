# 麻雀 v0.27

制作：鈾

[ブラウザで麻雀を開く](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## 今回の修正
- スマホの川をさらに拡大。上家・自分の川は牌幅24〜28px、左右の川は牌と中央の袋が重ならない範囲で19〜23px
- スマホの卓を幅に応じて縦長にし、6枚×3段の川と牌袋、名前、手牌が重ならないように再配置
- もともとの「川を見る」機能は残し、4人の捨て牌を大きな一覧でも確認可能
- 透明牌、血液量、CPUの自然な部分理牌、友達と遊ぶ部屋などは維持

候補レイアウトを320〜1440pxの画面幅で検証。各家18枚の川と手牌・名前・牌袋が重ならないこと、スマホの川の拡大機能が動くことを確認。

## オンライン版について
公開PeerJSサービスに依存する試験実装です。異なる実回線の端末同士の接続は未検証で、部屋主がブラウザを閉じると部屋は終了します。血液はゲーム内数値です。
