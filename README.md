# 鷲巣式透明麻雀 — ブラウザ試作版 v0.3

制作：鈾（原作とは無関係の非公式ファンメイド試作）

## 起動
`index.html` をブラウザで開くと、インストールせずにCPU対戦を試せます。ネット接続不要です。
GitHub Pagesの場合、公開リポジトリのルートに `index.html` を設置し、Settings → Pages → Deploy from a branch → main / (root) → Save を選択します。

## v0.3 の変更点
- 他家の透明牌の背面図柄を**左右反転のみ**（鏡映し）に変更。対面にも180°回転はしません。
- 筒子（1〜9筒）をSVGのカラー彫刻へ置き換え、色・縁取り・配置を見分けやすくしました。
- 右側の見える手牌一覧は不透明・白系背景を維持し、各牌を26〜27pxに拡大しました。タイルが溢れる場合は横スクロールで確認できます。
- 配牌、ツモ、打牌後も自動理牌をしません。指でドラッグ、または牌を選び左右ボタンで理牌します。
- 仮想血液の回復許可は部屋主の設定です。

## 現状の制限
- オフラインのCPU3人との試作です。オンラインの部屋対戦には未対応です。
- 役判定、符・点数、鷲巣麻雀の細則は完全版ではなく検証途中です。
- すべてゲーム内の架空数値です。現実の金銭や血液のやり取りはありません。

## GitHubに別リポジトリで作る
1. GitHubで公開リポジトリ `washizu-mahjong` を作成する（既存の人狼・ゲームセンターのリポジトリとは別）。
2. `index.html` と `README.md` をアップロードする。
3. Settings → Pages → Deploy from a branch / main / (root) → Save。
4. 数分後に `https://<あなたのユーザー名>.github.io/washizu-mahjong/` で公開。
