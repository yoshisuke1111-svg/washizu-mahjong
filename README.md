# 麻雀 v0.31 — 中央情報パネルを刷新

制作：鈾

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## v0.31
- 旧・円形牌袋パネルを、黒・濃緑・金のオリジナル四角型コンソールに変更
- **東／南の局数、本場、供託、残り牌数**を中央に集約
- 4人の席風と持ち点を、参加者ごとの視点に合わせて表示。**親**を金枠で強調、赤・緑チームの区別も維持
- **ドラ表示牌**を中央コンソール直下に固定
- 牌袋の鷲の意匠を中央に小さく残し、ツモ牌が袋から出る演出は維持
- スマホ320px幅では狭い中央部の点数の細かな数字だけを省略。川・手牌・操作ボタンの領域を確保
- これまでの透明牌割合、2対2、血液設定、CPU理牌、部屋コード、卓上の打牌・鳴き・和了ボタン、裏ドラの和了結果を維持

**独自デザイン**：参考動画の麻雀卓で一般的な情報の配置を参考にし、形状・色・飾りは独自に設計したものです。

## 注意
オンライン通信は公開PeerJSサービスに依存する試験実装です。異なる実回線同士での対局は完全検証できていません。原作特殊ルールと役・点数計算には未対応／簡易実装の部分があります。血液はゲーム内の数値であり現実の出血はありません。
