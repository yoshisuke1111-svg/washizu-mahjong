## v0.22
- iPhoneの録画で確認された、牌の枠はそのままなのに牌面だけ突然拡大・縮小する問題への対策
- SVGの絵柄はそのまま維持し、固定サイズのSVG画像として描画。牌面を牌の内側に固定
- CPU対局、オンライン部屋、透明牌の枚数設定、手動理牌、血液演出、スマホ用手牌、川の配置は維持

PCとスマホ幅のChromiumで、ツモ演出と繰り返し描画による牌面の大きさを検証。iPhone実機のSafariでの再確認は未実施です。

オンライン部屋は公開PeerJSサービスを利用する試験実装で、部屋主がブラウザを閉じると終了します。血液はゲーム内の数値であり、現実の出血・金銭取引はありません。
