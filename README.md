# 麻雀 v0.20 — CPU理牌・チーム表示・血液演出

制作：鈾

[ゲームをブラウザで開く](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

CPUとの四人麻雀、または友達と部屋コードで最大4人の2対2対局ができる試作版です。空席はCPU。

## v0.20 の更新
- CPUは配牌時に小さな組を部分的に理牌。筒子・索子・萬子を全部一か所に固めず、対局中も時々1枚だけ位置を動かす
- 緑チーム＝部屋主・対面の補佐、赤チーム＝右家の代表・左家の補佐。自分のチームを色と名前で強調
- ツモ牌の移動演出中も牌面の比率・サイズを保持し、独立した拡大を抑止
- 血液ゲージと数字が徐々に減り、増減量が表示される。精算画面にもアニメーションを追加
- 既存のスマホ用拡大手牌、タップでの手動理牌、透明牌枚数・血液レート・回復設定を維持

## オンラインについて
外部のPeerJSサービスを使う試験版です。別の実回線にいる友達との接続は保証されず、部屋主がブラウザを閉じると対局は終了します。ゲーム内の血液は演出用の数値であり、現実の出血・金銭取引はありません。原作ルールの細部は開発中です。
