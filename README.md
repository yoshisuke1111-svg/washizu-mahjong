制作：鈾

## 今回の修正
- スマホの川の牌を常時拡大（幅390pxの画面では約16px→22.5px、幅320pxでは約14px→19px）
- 卓を少し縦長にして、6枚×3段の川、中央の牌袋、左右・上下の手牌が重ならないように再配置
- もともとの「川を見る」機能は残し、4人の捨て牌を大きな一覧でも確認可能
- 透明牌、血液量、CPUの自然な部分理牌、友達と遊ぶ部屋などは維持

320px・353px・390pxのモバイル幅で、各家18枚の川を置いた状態の配置を検証。川同士と中央の牌袋が重ならないこと、拡大表示が開くことを確認。

## オンライン版について
公開PeerJSサービスに依存する試験実装です。異なる実回線の端末同士の接続は未検証で、部屋主がブラウザを閉じると部屋は終了します。血液はゲーム内数値です。
