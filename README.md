# 麻雀 v0.25

制作：鈾

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## 川の見やすさを改善
- 卓上の捨て牌を拡大。6枚×3段の固定配置を維持し、後から捨てた牌で以前の牌が移動しない
- スマホの手牌欄に「川を見る」ボタンを追加。自分・右家・対面・左家の捨て牌を切り替えて、大きな牌で一覧表示
- 卓上の捨て牌をタップしても対応する川を開ける。×ボタンやEscキーで閉じられる
- 透明牌、CPU対局、手動理牌、オンライン部屋、血液表示・演出などはそのまま

画面幅320・390・768・1440pxのブラウザで表示と切り替え操作を確認。

スマホの卓上に6枚×3段の川すべてを大きく置くと、中央の牌袋や手牌に重なるため、全体を拡大できる川専用表示も設けています。オンライン対局は公開PeerJSサービスを利用した試験実装で、実回線間での接続は未検証です。部屋主がブラウザを閉じると部屋は終了します。血液はゲーム内の数値です。
