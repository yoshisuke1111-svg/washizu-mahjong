## v0.28
- 和了時は、本人だけでなく味方・相手・CPUの和了も全員の画面へ強制表示
- 和了者の手牌、和了牌、副露、ロン・ツモ、成立役と翻数、合計翻数・符数を表示
- 表ドラの表示牌と対応牌を表示。立直して和了した場合だけ裏ドラ表示牌を公開し、裏ドラの翻数を計算
- ツモ・ロンの支払い内訳、立直供託、獲得総点数を表示
- 結果画面の血液増減演出は維持。スマホでもスクロールして全情報を確認可能
- 対局中の他家の不透明牌と未公開の裏ドラはオンライン参加者へ送らず、結果画面で和了者の牌だけ公開

従来のオンライン部屋、2対2、CPUの部分理牌、透明牌枚数設定、血液ルール、スマホ操作と川の拡大表示は継続。

**注意**：現時点の役判定・符計算はまだ試作実装で、一般的なリーチ麻雀のすべての役や例外には対応していません。今回の結果画面は既存エンジンが判定した役と点数を詳しく示します。オンライン通信は公開PeerJSサービスに依存する試験版です。血液はゲーム内の数値であり、実際の出血はありません。
