## 今回の修正

- 川の牌を少し大きくし、特に模様の余白を減らして読みやすさを改善
- 川を6枚×3段で固定し、名前・中央の牌袋と重なりにくい配置を維持
- 捨て牌をタップ／クリックすると大きく表示し、約2秒後に元へ戻る
- 透明牌、CPUの部分理牌、オンライン部屋、スマホの手動理牌などを維持

PC幅と320px・390pxのスマホ幅で配置と拡大表示を確認。

※オンライン通信は公開PeerJSサービスを使った試験実装です。部屋主がブラウザを閉じると部屋は終了します。血液はゲーム内数値です。
