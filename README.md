## v0.23 CPU理牌
- 配牌時に以前より多く対子・連続牌・小さな組を作る
- ツモ後も1〜2枚程度、ときどき3枚の位置を整える
- 一種類の牌を全部同じ側へ集めず、並び順も毎回異なる
- 人間の手牌には自動理牌を適用しない
- 牌の数・種類・所有者・役判定は変更しない

引き続きオンライン部屋、透明牌枚数設定、血液ルール、スマホのスワイプ手牌、タップによる手動理牌に対応。

オンライン通信は公開PeerJSサービスを使った試作実装で、友達との異なる回線での実機通信は未検証です。部屋主がブラウザを閉じると部屋は終了します。血液の表示はゲーム内数値のみです。
