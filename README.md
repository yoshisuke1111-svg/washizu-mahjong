## v0.30
- 打牌・立直・暗槓・手牌の並べ替え操作を、卓上の自分の川と手牌の間に移動
- ポン・チー・カン・ロン・ツモの選択も同じ場所にまとめる
- 和了や鳴きの確認が出ている間は、打牌などのボタンを隠して重複を防止
- 打牌ボタンは牌を選ぶまで押せない表示、選ぶと有効になる
- 川の未使用の段を避けて操作ボタンを表示し、打牌が進むと位置が下がる
- スマホは2枚タップで理牌。PCは矢印とドラッグによる整理も継続

**注意**：オンライン部屋は公開PeerJSサービスに依存する試験版です。現在の役判定・符計算は開発途中で、競技麻雀のすべてのルールには対応していません。血液はゲーム内数値であり実際の出血はありません。
