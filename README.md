# 麻雀 v0.18 — オンライン対局（試験版）

制作：鈾

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## 友達と遊ぶ
1. 部屋主が名前とルール（透明牌の枚数、血液レート、回復可否、半荘数、CPUの速度など）を決めて「部屋を作る」
2. 生成された「招待URL」を友達に送る。部屋コードは手動指定も可能
3. 参加者は名前と希望の席を選択して入室（2番席は部屋主の味方）
4. 部屋主が「対局開始」。空席はCPUが代行

8索は見本に近い二段交差模様に変更。2枚タップによる理牌、透明牌表示、自動ツモ演出などを維持しています。

## 重要な制約
- 通信には公開PeerJS Cloudを使います。NATや回線・公開サービスの状態で接続できないことがあります
- 部屋主のブラウザが進行を管理します。部屋主が閉じると部屋は終了
- 異なる実回線間での接続は未検証です。模擬ブラウザ接続では2〜4人の入室・打牌同期と手牌秘匿を検証済み
- オンラインモードや原作の特殊ルールは試験実装です
- 血液はゲーム内数値のみ。現実の出血・金銭取引はありません
