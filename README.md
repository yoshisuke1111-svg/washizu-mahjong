# 麻雀 v0.29 — 卓上の鳴き・和了操作

制作：鈾

[ブラウザで遊ぶ](https://yoshisuke1111-svg.github.io/washizu-mahjong/)

## v0.29 変更点
- ポン・チー・カン・ロンの選択肢を、卓の上で自分の川と手牌の間に表示
- ロンの選択時も「キャンセル」を表示。選ばなければロンを見送って進行
- ツモ和了可能なときは、卓上に「ツモ」「キャンセル」を表示
- ツモをキャンセルしても打牌前の手番は継続。ボタンはそのツモの間だけ閉じ、後のツモチャンスには再び表示
- オンラインの参加者にも同じ操作を表示。ロンのキャンセルは部屋主へ「パス」として通知
- 従来のスマホ用大きな手牌、手動理牌、赤・緑チーム、血液演出、ドラ／裏ドラと和了詳細は維持

### 補足
- 「キャンセル」は**宣言前に見送る**操作。ロン・ツモを確定したあとに和了を取り消す機能ではありません
- ロンの見送りは通常の一時フリテンの対象になります
- 現在の麻雀エンジンは試作段階で、すべての役や例外を厳密に再現しているわけではありません

オンライン通信は公開PeerJSサービスによる試験実装です。部屋主がブラウザを閉じると対局は終了します。血液はゲーム内数値です。
